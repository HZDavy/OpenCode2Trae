Why

它解决什么问题

一句话：Trae 少了 OpenCode 要的一张「通行证」，本程序专门负责补上它。 下面用大白话讲清楚整件事。

01

OpenCode 要求「刷卡进门」

OpenCode Go 要求每个请求都带一个叫 x-opencode-session 的请求头——就像进楼要刷工牌。

02

可 Trae 没有这一栏

Trae 的「自定义模型」设置里没有地方能填请求头，于是它一直被挡在门外，只能回来报错。

03

所以中间加个「前台」

本程序在本机 127.0.0.1:8787 开个前台：接住 Trae 的请求 → 替它补上通行证 → 转给 OpenCode → 把结果原路送回。

# 之前：Trae 直接用 OpenCode，被拦下 WebSocket error: Network IO error: error sending request for url (…/v1/chat/completions) (HTTP Status: 500) (4028) # 现在：Trae → 本机中转站 → OpenCode 桥接已启动：http://127.0.0.1:8787 转发目标：https://opencode.ai/inference/go/… 两种格式都支持：OpenAI 走 /v1，Claude 走 /anthropic/v1 ✓ 请求已补上通行证，正常返回

全程只在你自己的电脑上跑，不经过任何第三方服务器。

Get started

怎么用（三步）

从下载到在 Trae 里用上，不超过两分钟。

  1. 1

    启动桥接

    双击 OpenCode2Trae.exe，点界面最上面的「启动桥接」，左上角指示灯变绿即成功。

  2. 2

    填好密钥

    切到「接入地址」页，把 Go 套餐的密钥粘进去、点「保存」。

  3. 3

    在 Trae 里添加自定义模型

    模型设置 → 添加自定义模型，按下表填请求地址；模型 ID 到「模型清单」页复制。

Claude Anthropic Messages http://127.0.0.1:8787/anthropic/v1

界面里把「完整 URL」开关打开的话，就填各自带 /chat/completions、/messages 的那一版。 本程序需要一直开着；开了托盘模式后关掉窗口会收进托盘继续跑。

FAQ

常见问题

它会看到我的密钥吗？数据会被上传吗？
程序只在本机 127.0.0.1 上监听，不对外开放，也不向任何第三方服务器上传数据。 你的密钥只写在本机配置文件 opencode2trae-config.json 里（明文），不上传。
报「不支持图片输入」怎么办？
这是模型本身的能力限制，不是桥接坏了。去 Trae 的高级配置里把「支持图片输入」关掉即可。
报 401 之类的鉴权错误？
基本是密钥的问题（填错、过期、没用 Go 套餐的密钥），不是桥接坏了。重新到「接入地址」页粘贴保存一次。
关掉窗口以后 Trae 就连不上了？
本程序必须一直开着——它就是那条「中转通道」。如果你希望关窗口不退出， 到「设置」里打开「托盘模式」，关闭按钮就会变成收进系统托盘。
需要先装 Python 吗？
不用。直接到 Releases 下载 OpenCode2Trae.exe 双击即用。想跑源码的话，Python 3.8+ 自带 tkinter 就够，不需要 pip 装任何东西。
这是 OpenCode 或 Trae 官方的软件吗？
不是。这是一个个人开源项目，与 OpenCode、Trae 官方均无关联。所用接口来自公开渠道，可能随时变更或失效， 请在遵守相关服务条款的前提下使用。
